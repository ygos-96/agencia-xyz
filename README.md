# Landing page · Agência XYZ

Landing page de uma agência fictícia, feita como exercício de layout responsivo com HTML e CSS puros.

**Online:** https://ygos-96.github.io/agencia-xyz/

## Seções

- **Cabeçalho** com logo e menu de navegação.
- **Hero** com chamada principal.
- **Sobre** com blocos de texto.
- **Serviços** (SEO, landing pages e outros).
- **Projetos** e **rodapé** de contato.

## O que pratiquei

- Estrutura semântica com `header`, `section` e `footer`.
- Variáveis CSS (`variables.css`) para cores e espaçamentos, e um reset próprio.
- Menu de navegação estilizado em arquivo separado (`menu.css`).
- Responsividade com `@media`, adaptando o layout para telas menores.
- Ícones com Font Awesome (fontes locais) e GIFs de demonstração da versão desktop e da versão responsiva.

## Como está organizado

```
index.html
src/css/       reset, variáveis, estilos, menu e Font Awesome
src/images/    imagens e GIFs de demonstração
src/webfonts/  fontes dos ícones
```

## Rodar localmente

Abra o `index.html` no navegador ou use um servidor estático:

```bash
npx serve .
```

## Observações

É um projeto de estudo: os textos são de exemplo (placeholders) e não há formulário nem back-end. O foco foi o layout.
